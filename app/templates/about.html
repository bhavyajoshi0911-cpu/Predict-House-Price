HomeValue AI Overview

HomeValue AI is a full-stack real estate valuation and analytics web application engineered as an advanced AI/ML portfolio project. It demonstrates modern end-to-end machine learning engineering: from exploratory data analysis and data preprocessing with zero data leakage to comparative ensemble training, defensible uncertainty quantification, SQLite persistence, and an enterprise SaaS dashboard.

Educational & Portfolio Demonstration Predictions generated by this application are mathematical estimations based on historical King County sales patterns. They are intended for educational and analytical purposes, not formal certified bank appraisals.

Machine Learning Workflow

1. Data Ingestion & Cleaning

Parses the King County House Sales dataset. Filters duplicates, validates non-zero target prices, enforces realistic physical constraints (bedrooms between 1–15, living areas > 200 sq ft), and normalizes postal zipcodes.

2. Zero-Leakage Preprocessing

Implements scikit-learn's ColumnTransformer. Numerical features (sqft living, lot, grade, bathrooms) are standardized with StandardScaler. Postal zipcodes are encoded using OneHotEncoder(handle_unknown='ignore') strictly on training data.

3. Multi-Model Benchmark

Simultaneously fits: (1) Linear Regression baseline, (2) Random Forest Regressor (100 trees), and (3) Gradient Boosting Regressor. Models are evaluated on an identical held-out 20% test split.

4. Defensible Uncertainty Intervals

Instead of fabricating arbitrary confidence ranges, prediction intervals are calculated via an empirical 90% tolerance bound using the test Root Mean Squared Error ($\pm 1.645 \times \text{Test RMSE}$).
